Delaunay Triangulation Visualization

  While learning about Geographic Information Systems (GIS) one concept that I found interesting was delaunay triangulations. Despite being an important concept, the learning tools that exist for understanding this concept are very lacking. For this reason I created a web app using Flask and Javascript that can be found here, which lets users explore the incremental construction algorithm by giving their own point set and viewing each step in the algorithm. I also made a standalone application in Python and wrote a report on the topic which can be found on my github here.

RPG Game

  This is a project I made to get familiar with working inside the GB Studio game development environment, where you can walk your hometown, interacting with your neighbors and items. While very simple, this project made me appreciate the restrictions that were present when developing games for old school handheld devices. All source code is on my github.

Neureset EEG Treatment Device Simulator

   For this project the goal was to use Qt creator with C++ to create a simulation of an EEG treatment device. The device would use nodes placed on a patients head to read electronic signals and stimulated those areas with electronic signals to deliver treatment. This project was done in a small group where we were encouraged to use the Agile methodology for collaboration. Since this project was affiliated with my university I'm not able to have the source code public on github but you can view a short demo video of the simulation to the right.

Quantum Encryption Scheme

   For a Quantum Comminications course I took we had an open ended final project where we needed to make some sort of software that was related to quantum computing. For this project I decided to embrace the course topics and go with an implementation of a quantum encryption scheme which was inspired by a paper by my professor Michiel Barbeau. The encryption scheme uses Clifford Gates and Permutations to encrypt quantum data and was implemented in Matlab's simulated environment. This project was super neat since the simulated environment allowed us to do so much stuff that would not be very feasible in a physical environment but these encryption scheme will be very applicable and useful once the technology is able to catch up. There is a full report, demo and matlab source code on my github here.
